# Studio Atlas

A small workspace for a sample branding project.

## Deliverables

- A visual direction and a short creative brief
- High-resolution exports for web and print
- A tidy archive with final source files

## Review checklist

1. Preview the moodboard and compare revisions.
2. Confirm export names and dimensions.
3. Move approved files into the Final folder.

> This workspace contains demonstration files only.
