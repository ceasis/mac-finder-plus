Workbench

Productivity · Utilities · Built by QnSub Tech · macOS 14 or later

Built for creators, developers, students, and heavy Mac folders

Workbench combines familiar macOS-style browsing with focused power tools for downloads, screenshots, media libraries, research folders, and project cleanup.

Dual-Pane Browsing

Work across two folders at once, move files between panes, use keyboard-friendly navigation, and switch between list, icon, and column-style workflows.

Media Preview

Preview images, video, and audio inside the workspace, resize images, rotate or flip media, convert supported files, and make quick visual decisions faster.

Disk Cleanup

Analyze disk usage with visual summaries, identify large deletion candidates, filter by date, size, type, file, or folder, and clean up crowded directories with less guessing.

Notes and Snippets

Keep notes with dragged images, audio, video, and file attachments. Save reusable snippets of text, images, audio, and files with quick copy or open actions.

Focused File Tools

Create text files quickly, move selected files into a new folder, inspect archives, compare folders, browse metadata, and use right-click tools for common file work.

Local-First Privacy

No analytics SDKs, no ad SDKs, no account tracking, and no cloud sync. Workbench works with files on your Mac and stores app data locally.
